# Bekasku Web Nuxt (Marketplace Web V3)

Aplikasi Web Resmi Marketplace Jual Beli Barang Bekas & VVIP Preloved #1 di Indonesia (**Bekasku V3**).

---

## 🛠️ Tech Stack & Architecture
- **Framework:** Nuxt 4 (Vue 3.5 + Vite + Nitro)
- **Styling:** Tailwind CSS v4 + Custom Glassmorphism & Mesh Design Tokens
- **Icons:** Lucide Icons (`lucide-vue-next`) — *Tanpa Emoji / Emoticon*
- **Dev Port:** `3050`
- **Brand Colors:**
  - Primary: `#2563eb` (Royal Blue)
  - Secondary: `#ebad25` (Amber Gold)
  - Dark Surface: `#0b0f17` & `#131b2a`

## 💻 Cara Menjalankan Secara Lokal

```bash
# Masuk ke direktori proyek
cd bekasku-web-nuxt

# Install dependensi
npm install --legacy-peer-deps

# Jalankan server pengembangan
npm run dev
# Akses di browser: http://localhost:3050
```
